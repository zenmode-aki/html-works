# 本人のメモ その4「オリバー・バークマン ブログ18本のエッセンス」（2026-10-05 本人が添付。本人の口調のまとめ）
# 本人はバークマンの大ファン（Kindle 4冊・Audible 3冊、『Meditations for Mortals（imperfections）』を週1で読み返した。生粋の完璧主義者で生産性オタク）
# → これは本人の事実なので「私は完璧主義なので刺さりました」などに使ってよい（draft/oliver-burkeman-blog/ の記事にある）
# 😂 = バークマン本人が自分の記事で書いている笑い話。「バークマンさんは〜と書いています」の形で使ってよい（本人が自分で公開している話）。
#    ただし彼の家族（パートナー・子ども）の話は使わない。生きている有名人（サインフェルドなど）の発言は「バークマンさんによると〜らしい」程度に短く、カギカッコの直接引用にしない。

① 毎朝「借金ゼロ」からスタート（/donelist）「今日やれたことって、全部ボーナス」
- 毎朝「やらなきゃ」という借金を背負って始めるから、どれだけやっても足りない気がする。スタートをゼロにすれば、やったことは全部プラス
- 借金スタート -100 → がんばる → -63「まだ足りない」／ゼロスタート 0 → コーヒー+1 → メール+1 → +2「黒字じゃん」
- 「生きてるだけで何かを返さなきゃ」という見えない借金は、そもそも存在しない。やることは無限に増えるので「全部片付ける」は無理
- done list（やったことリスト）をつける。しんどい日は「歯を磨いた」でもカウントしていい
- 😂 夕方6時にジントニックを作るのが日課だが、それは done list に書かないらしい

② 本気の集中は1日3〜4時間で十分（/fourhours）「4時間だけ守れば、あとはぐちゃぐちゃでもいい」
- ダーウィンも数学者ポアンカレも、本気の仕事は1日4時間くらい。それ以上を自分に求めない
- 「長く働けばその分進む」は思い込み。元気な時間帯に3〜4時間の「聖域」を作り、残りがメールや会議でぐちゃぐちゃでも気にしない
- 大事なのは「もっと頑張る力」ではなく「終わってなくても手を止めて休める力」
- 😂 ある修道院の作業時間もやっぱり3時間。「終わらなかったら？」と聞かれた修道士の答えは一言「気にするな」

③ ニュースの中に住まない（/newslife）「世界は変えられないけど、今夜のパスタは作れる」
- 世界のニュースは自分の力が0%の場所。そこに心の重心を置くと無力感ですり減る。自分が影響できる日常（家族・夕飯）に片足を戻す
- SNSでシェアしても「参加してる気分」になるだけ。ニュースを見るなではなく、感情の投資先を自分の生活に移す
- 正気を保って人生を楽しむのは、わがままじゃない。世界は正気な人を必要としている
- 😂 「影響できる世界」の例に、犬のフンを片付けない近所の人を挙げて「まあ、その人にはまだ何の影響も与えられてないけどね」と自分で落としている

④ 「リセットして新しい自分」は幻想（/freshstart）「もう失敗してるんだから、安心して始めればいい」
- 「今日から生まれ変わる」は完璧主義の一種。遅れも失敗ももう起きていて取り消せない。認めた瞬間に、やっと本当に変われる
- 人生は航海中の船：港に戻って新しい船に乗り換えるのは無理。海の上で一枚ずつ板を直すしかない
- 変わろうとしている自分も過去に作られた自分（自分の髪を引っ張って沼から抜け出そうとするようなもの）
- 「完璧な人生」はもう無理だと確定している → だから肩の荷が下りる。合言葉「ちょっと待って、もしかしてこれがそれなんじゃない？」
- 😂 「今を生きよう」と聞いても「よし、明日の朝から毎日瞑想して今を生きる人間になるぞ！」と計画してしまう自分にツッコんでいる

⑤ 書く→やる→消す（/onething）「人間って、もともと1つのことしかできない」
- 緊急事態で落ち着けるのは「今やること」が1つに決まるから。普段も紙に1つ書いてそれだけやれば同じスッキリ
- 手順：①今やる価値がありそうなことを1つ（ベストでなくていい）②紙に書く ③やる ④線を引いて消す ⑤1に戻る（昼寝もアリ）
- マルチタスクは「不安だから注意をパタパタ切り替えているだけ」。どんな生産性ツールも目的は「今やる1つを少しうまく選ぶ」だけ
- 「1つに集中しろ」と縛るのではなく「そもそも1つしかできない」と気づくと楽
- 😂 「緊急時に強い人」と言われる理由は「普段うじうじ悩んで周りをイラつかせているから」

⑥ 人生の「管制塔」には登れない（/reality）「人生を上から操るんじゃなくて、自分が人生そのもの」
- 「全部把握したい」「先に雑用を片付けてから本番」は、現実の外に出て神様のように人生を操りたい幻想。現実の外には出られない（最初から川の中、泳ぐしかない）
- 「これが片付いたら本当の人生が始まる」日は一生来ない
- 何かを選ぶ＝他の何百万個を「やらない」と選ぶこと
- 全部を把握できないのは、だらしないからではなく、自分がその「全部」の一部だから。やることは「次の数時間で一番意味がありそうなこと」だけ
- 😂 自由意志の記事を紹介して「読むかどうかはあなたが選んで…いや、選べないのかも！」と自分でツッコみ、「そもそも選べるならの話だけどね」で締める

⑦ 毎朝3ページ（/morningpages）「3ページだけ書けば、あとは何かが勝手にやってくれる」
- モーニングページ：手書きでノート3ページを、誰にも見せない文章で埋める。ルールは「ペンを止めない」。書くことがなければ「書くことがない」と書く
- 決まりは「3ページ」だけなので、アイデアをいちいち評価しなくなる。量を出すとたまにいいのが混ざる（質は量から）
- 頭の中身を紙に出すと、他人の悩みを見るように自分を外から見られる（一種の瞑想）
- 成果のためではなく「儀式としてただやる」。全部をコントロールしたがる頭を休ませる
- 😂 冒頭で「毎朝6時きっかりに起きて、ブラジル産シングルエステートのコーヒーを淹れて…ってのは嘘で！」とノリツッコミ。実際は週7日中4日くらい書いている

⑧ 宇宙から見れば、ちっぽけ（/nobigdeal）「自分がちっぽけだとわかると、むしろ自由になれる」
- 大雪や壮大な景色を見ると「自分は宇宙のちっぽけな点」と思い出してストレスが消える。「宇宙的ちっぽけさセラピー」
- 庭の雪 → 街 → 国 → 地球 → 無限の宇宙 …の中の点が私。「あ、別に大丈夫じゃん」
- 心のどこかで「自分は宇宙的に大物」と思っているから、何もかも「失敗したら破滅」に感じる
- 「宇宙から見ればどうでもいい」と思い出すと、意味のあるリスクを取れ、どうでもいいことは放っておける
- 赤ちゃんにミルク・家賃を払うは大事なまま。変わるのは「何が大事かを測るものさし」。悩みの99%は悩む価値がないと気づく
- 😂 「宇宙的ちっぽけさセラピー」を「公式に商標登録した（してない）」。ジョブズの「宇宙に凹みをつける」に「iPhoneでさえ本当に宇宙を凹ませた？」とツッコむ

⑨ 考える前に、やっちゃう（/justdo）「先延ばしのほうが、実はしんどい」
- 2分で終わることは今やる（『GTD』デビッド・アレンの2分ルール）。メモや予定に入れる手間のほうが重いことがある
- やることの本当の時間＝やる2分＋考える時間＋気にしてる時間＋午前3時に思い出す時間 → 今やるのが一番ラク
- 瞑想の先生ジョセフ・ゴールドスタインは「優しくしたいと思ったら、その場でやる」がルール。自然にそう思えた瞬間を逃さない
- 優しくできないのは心が狭いからではなく「ちゃんとしたメッセージを送りたいから他を片付けてから」とハードルを上げすぎるから
- 自分への優しさも同じ。すぐやるのは根性ではなく、自分を楽にする方法
- 😂 「掃除機の紙パックを注文する」リマインダーを3回も別々に作っていた。注文したほうが早かった

⑩ 何が起きてもおかしくない。でも、たぶん何とかなる（/anythingcouldhappen）
- 不安は「今は存在しない危険を怖がっている状態」。でも悲しいことはいつ起きてもおかしくない。不安を消そうとせず「それでも少しずつ動く」で「何とかできる」証拠を集める
- 映画：不穏なBGM → 事件 → 心の準備OK／現実：BGMなしで突然起きる（※この気づきはバークマンのパートナーの話なので、人の話にせず「映画と違って現実にはBGMがない」と一般化する）
- ストア派の「最悪を想像する」（スピーチで大恥をかいて布団にもぐる、まで想像 →「それなら耐えられる」）は使える。ただし不安な人は本当にやばいことも起こりうると知っている。不安は自然な反応
- 救いは2つ：①どうやっても変えられないから力を抜くしかない ②全員が同じ船。自分より人生をコントロールできている人は誰もいない
- 一番効くのは行動。「考え方を変えてから動くより、動いて考え方を変えるほうが簡単」
- 未来をコントロールできたことは一度もない。でも今まで人生に完全に潰されたこともない。そもそもコントロールは必要なかったのかも

⑪ 気が散るのは、自分から逃げてるから（/distraction）「大事なことは、ちょっとしんどくて当たり前」
- スマホに引きずり込まれているのではなく、自分から喜んで逃げている。難しい仕事や退屈の「ちょっとした不快感」から逃げたくて開く
- 「画面の向こうには引き止めるために給料をもらっている人が1000人いる」は本当。でも私たちも協力者になっている
- 意味のあることは自分の限界を突きつけてくる。「自分は限られた人間だ」という感覚から逃げたくなる
- ブロックアプリやノイキャンは逃げ場所を封じるだけで、不快感は残る（窓の外を眺める、おやつを取りに行く）
- 解決策は「大事なことはずっと快適であるべき」という期待を捨てること。ちょっとした緊張や退屈は「入場料」
- ただし「ちょっと」の話。めちゃくちゃしんどいなら、やることが間違っているサインかも
- 😂 「やりたい仕事中にほんのちょっと疲れたり退屈しただけで、嬉々としてSNSに飛び込んで1時間溶かしている」と告白

⑫ 時間と戦わない（ポモドーロの本当の意味）（/time）「時間は倒す敵じゃなくて、一緒に歩く味方」
- ポモドーロ（25分作業＋5分休憩、4回で長めの休憩）の本当のポイントは「時間を支配する」ではなく「自分の時間は限られていると受け入れる」
- 時間との戦いに勝った人間は今までいない（最後は全員死ぬので）← 重くならないよう言い換えてよい「時間はいつも最後に勝つ」
- 自分は時間と別の存在ではなく、毎日の時間の積み重ねそのもの。1日は最初から「時間の塊」が並んでいるだけ
- 知られていないルール：予定より早く終わっても次のタスクに進まない。残りは見直しに使い、「急ぎたい」そわそわに慣れる練習
- 😂 最初は「ふーん、何がそんなにすごいの？」と思っていて、良さに気づくのに本を1冊まるごと書く必要があった

⑬ 変化は「気まずい」のが正解（/awkwardness）「しっくりこないってことは、たぶん合ってる」
- 自分を変える行動はだいたい気持ちよくない（サイズの合わないシャツ、利き手じゃないほうで字を書く）。その気まずさが変わり始めたサイン
- 今までの人生は全部「今の自分でいる」練習だったので、違うことをするとぞわぞわするのは当然
- 新しい手帳術や効率化本に「これだ！」と興奮するのは警告サイン（防御を固めているだけ）。本当に効いたのは「一気に詰め込まず少なめを毎日」で、それはむしろ不安で居心地悪かった
- 気分メーター：🤩ワクワク→たぶん防御／😬気まずい→たぶん必要な変化／😱怖すぎ→やってみると「熟しすぎたバナナ」程度
- ただし「本能」と「直感」は別。「この夜道は危ない」「この人はやばそう」という直感は信じる
- 避けていた感情を味わってみても全然死なない。座り心地の悪い椅子、傘を忘れた雨の日くらいの「ちょっといや」で終わる
- 😂 クセは「生きていていい理由を証明するため全力でやらなきゃ」。全力でやって…そのうち腹が立ってきて…「ストライキに入る」

⑭ 書くのをラクにする3つのコツ（/onwriting）「書くって『ほら、あれ見て！』って指さすこと」
- ① いい文章は指さし：見つけた面白いものに読者の目を向ける。賢さを見せつけない。どの詳細が必要かも自然にわかる
- ② やめるのも始めるのと同じくらい大事：時間や文字数に達したら、調子がよくてもやめる。最初は10〜15分。「もっとやりたい」は焦り。止めることで毎日戻ってこられる「忍耐の筋肉」が育つ
- ③ 白紙をにらんでいたらやり方が間違っている：読んだこと、話したこと、シャワー中の思いつきをメモに貯める →「書く」は組み合わせる最後の工程。本格的には「ツェッテルカステン」
- 😂 有名な文章本の「不要な言葉は省け」に「不要だとわかってたら最初から省くし、わからない人には何の役にも立たなくない？」とツッコむ
- （本人は記事の原稿の横に「📦 情報源.txt」というメモの倉庫を置いている ← ③と相性がいい。使うなら軽く）

⑮ 人生は一生「整わない」。それでOK（/never）「悩みがなくなる日は来ない。だから今を生きればいい」
- 「今はまだ仮の人生で、全部整ったら本当の人生が始まる」と思っているが、その日は来ない。認めると肩の荷が下りてやる気が出る
- 悩みは「堆肥」。臭いけど、ものを育てる
- ある友人がサム・ハリスに「いつか悩みが全部なくなる日が来ると、まだ思ってるの？」と聞いた
- ケインズ：そういう人は「猫を愛さず、その子猫を愛し、実は子猫の子猫を愛している」。目の前の猫は一生愛さない
- 習慣本の「一度身につけば一生ラク」も同じ罠
- 瞑想のゴールは雑念ゼロではなく「気が散ったら、また呼吸に戻る」を繰り返すこと。ランニングも「サボった次の日にまた始めるのがうまくなる」を目標に
- 「メールには一生追いつけないかも」と想像すると、不思議と楽になる（※パートナーの例は使わない）
- 😂 「悩みのない時期は一生来ない」と思った瞬間、まず「え、話が違うじゃん！そんな契約してないんだけど！」とムッとするらしい

⑯ 積ん読は「バケツ」じゃなくて「川」（/river）「全部読むのは、そもそも自分の仕事じゃない」
- 読みたいものがたまるのは、いらない情報が多いからではなく「読みたいもの」が多すぎるから。空にするバケツではなく、流れていく川。たまにいいものをすくう
- 昔は「情報過多はフィルターがしょぼいせい」。本当の問題は「フィルターが優秀すぎる」こと。いいものだけ届くから全部読みたくなる
- 「干し草の山から針を探す」ではなく「干し草の山ぐらいの針の山」に埋もれている。全部大事だからしんどい
- 「大きな石から先に瓶に入れろ」も、実際は大きな石が多すぎて入らない。一番大事なものを選び、他の大事なものを放っておく覚悟
- 図書館の未読の本には焦らない。「全部読むのが自分の仕事」と思っていないから
- 😂 「不可能なことは、実際にはできない。（ヒント：名前に書いてある）」を最強のテクニックとして紹介

⑰ 習慣は「だいたい毎日」（/dailyish）「毎日じゃなくて、だいたい毎日」
- 「毎日絶対」は1回サボった瞬間に全部どうでもよくなる。「だいたい毎日（dailyish）」のほうが結局たくさんできる
- 毎日ルール ✅✅✅✅❌ →「もういいや」→終了／dailyish ✅✅❌✅✅✅❌✅✅✅✅❌✅…ずっと続く
- 有名な「カレンダーに✖をつけて鎖を切らすな」（サインフェルド・テクニック）。バークマンが本人に聞いたら「一度ある人に言っただけ。話す価値もない」という感じだったらしい（※直接引用にしない）
- 「だいたい毎日」は甘えではない。週1、2回では勢いはつかないのでプレッシャーはかける。ただ強制しない
- 「成果を自動で生む魔法のテクニック」はない。欲しがるときは裏の理由（やり方がわからない、実はやりたくない、完璧な記録で自分の価値を証明したい）
- 大事なのは記録が完璧かではなく「何が生まれたか」

⑱ 「次に手を動かすこと」を書く（/physical）「頭の中は無限。でも、手でできることは有限」
- やることリストには、体を使って実際にできる具体的な行動を書く。頭の中やネットだけで考えていると、ふわふわ浮いて先延ばしする
- ✖「車を直す」→ ○「整備士に電話する」／✖「下調べをする」→ ○「5ページ以内のまとめを印刷する」
- 『GTD』のデビッド・アレンも、いいToDoは「手足でできる次の行動」。カル・ニューポートは「計画を立てる」なら「2ページの計画書を印刷して手に持つ」をゴールに
- 頭の中とネットには限界がないので神様気分になれるが、「現実に影響を与えている感覚」がなくなって少し落ち込んだりもする
- 「決断する」も「決めたことを1ページのメモにする」にすればモノとして形になる
- 意味は、体を持った自分と、限りある現実の世界とのやりとりの中で生まれる
- 😂 「壮大な哲学的背景があるが今回は触れない。理由の一つは、自分が理解してないから」

まとめ「全部は無理。だから安心して、目の前の1つをやろう」
- 「人生を完璧にコントロールしたい」願望が全部のしんどさの原因。手放すと動けるようになる
- 合言葉：💰借金ゼロスタート／🔢人間は1つのことしかできない／🚢航海中の船、港には戻れない／😬大事なことはちょっと気まずくてしんどいのが普通／⏹️止める勇気（4時間、だいたい毎日、未完成でも休む）／🌊川として扱う（積ん読もニュースも全部は取らない）／🌌宇宙から見ればちっぽけ、だから自由／🏃考えるより動くほうがラク
