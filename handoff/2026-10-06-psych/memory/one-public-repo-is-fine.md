html-works は公開リポジトリ1つのまま運用する。下書き（/draft/）・原稿・WORK.md・goals/・me/ が URL で開けることは本人が承知のうえで OK（2026-10-03、本人が判断）。

**Why:** 本人は Mac mini・スマホなど複数の端末と複数の AI（Claude Code・Codex など）からこのリポジトリを動かす。リンクを渡してどの端末でもすぐ読めることのほうが大事。サイトから GitHub へのリンクはなく、URL を当てずっぽうで探られることはないと考えている。リポジトリを2つに分けるのは「AIも人も分かりにくくなる」ので避けたい。

**How to apply:** 公開範囲の変更（private 化・リポジトリ分割・履歴の書き換え）を提案し直さない。代わりに、誰でも読む本番の記事（works/）の中身はブログ憲法 第1条どおりに直す。構成は「どのAIが来ても分かりやすい」ことを優先する。関連：[[html-works-multi-ai]]
