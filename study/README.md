# 15秒の勉強ノート

勉強中のことを、**15秒（長くても30秒）で読めるようにメモしておく**サイトです。
大きく学んでいるのは **IT** と **自制心**。ほかは「その他・興味あること」に閉じてあります。日本語・English・한국어 で読めます。

- 公開先：https://15-second-blog.com/study/ （html-works の `study/` フォルダ）
- aki-os の `projects/html-works/study/` にも同じものがあります
- 日常の話は「ともだちんこブログ」（15秒ブログ）へ。全ページのいちばん下にリンクがあります

| 場所 | 何か |
|---|---|
| `index.html` | トップ（IT・自制心・その他 の3つの箱） |
| `posts/` | 記事。1本＝1ファイル |
| `images/` `images/icons/` | 画像とタグのアイコン |
| `assets/site.js` | **設定（日常ブログのURL・Googleフォームの URL）・ことば・共通フッター。URL はここだけ直せば全ページに反映** |
| `CLAUDE.md` / `AGENTS.md` | AI が守るルールと、記事の追加手順 |

記事を足すときは、AI に「◯◯のことをメモしたい」と言って中身を話すだけ。くわしくは [CLAUDE.md](CLAUDE.md)。
