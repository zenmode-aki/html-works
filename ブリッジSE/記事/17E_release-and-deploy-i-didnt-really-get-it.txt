Honestly, I used the words pretty loosely back then 🐧

I'd say "let's deploy" or "let's release,"
depending on the mood of the day.

Deploy is putting the code you built into an environment.
Release is making it public, so users can actually use it.
That's roughly the difference, I think.

Even when I heard "the instance is spiking" in an internal meeting,
