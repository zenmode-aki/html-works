Adults should start learning from what they can use right now 📚

🧠 Psychology📚 Learning📖 Books
🤔 Sound Familiar

When you think "I want to study something," do you ever not know where to start?

📖 The Point

For adults, I recommend starting with "things you can use right now."

🚀 The Reason

This is because if you use today's lesson tomorrow, you can see the result soon.

When you see the result, it becomes fun, and it is easier to keep studying.

🔀 For Example

For example, if you always get nervous when you talk to people, a book on talking may come before a thick test book.

If you go to Korea next month, start with short phrases for your trip.
