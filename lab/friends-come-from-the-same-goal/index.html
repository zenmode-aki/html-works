Friends come naturally from the same goal or the same interest 🧲

🧠 Psychology🤝 Friends😊 Happiness
🌱 Sound Familiar

In a new place, do you ever worry, "How can I make friends?"

🧲 The Rule

It is said that friends come naturally between people with the same goal or interest.

This is because when you like the same thing, you can find things to talk about easily.

🏐 Dodgeball Days

When we were children, too, kids who liked dodgeball became friends with each other.
