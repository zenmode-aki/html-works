# 📥 あとで記事にするもの

**スマホからGitHubに下書きを置くための、一時置き場です。**

外にいるときに思いついたネタを、ここにフォルダを作って放り込んでおく場所。
パソコンの前に座ったときに、ここから記事にしていきます。

## 使い方

1. ここに `ネタの名前/` というフォルダを作る
2. その中に `本文.md` を置いて、思ったことをそのまま書く（口調も誤字もそのままでいい）
3. 写真があれば `images/` に入れる

## ルール

- **記事にして公開したら、ここからは消す。** ここに残すのは「まだ記事になっていないもの」だけ
- **これから何本も増えるシリーズは、ここに置かない。**
  トップレベルに専用のフォルダを作る（`クラーク/` `バギオ/` `ブリッジSE/`
  `ネットワーク運用保守/` `旅/` `名古屋と家族/` `勉強と資格/` と同じ形）。
  一本ものだけをここに置く
