Start each day at zero, and everything you do is a bonus 💰

🌅 Morning Debt

Every morning, we often start the day with a debt of "I have to do it." So, however hard we work, we feel, "It is still not enough."

👻 No Such Debt

But that invisible debt does not exist in the first place.

🟢 Start At Zero
