今回、妹を海外の大学に送り込むためのプロジェクトで使ったツールは、この3つです 🐧

GitHub — すべてのデータの置き場です。妹の高校の成績、高校からもらった進学に関する資料、候補の大学8校それぞれの情報、最新のチャット履歴、なんでも入れました。

Claude Code — GitHubの情報を使って、いろいろ相談しました。GitHubの中の情報を整理したり、直したり。妹に関係するメールやWhatsAppが届いていないか確認させたりもしました。

Claude in Chrome — Chromeを使った操作全般です。これがとても便利でした。大学の問い合わせフォームや、ホテルや飛行機の予約など、ブラウザの操作がたくさん必要なとき、このクリックして入力する作業を、ほとんどこのAIに任せていました。

やはり、めっちゃお世話になった機能がClaude in Chromeです。

これはClaudeがブラウザ操作を代わりにしてくれるものなんですが、いろんなウェブフォームのぽちぽち作業が代替されたのは、とても助かりました。
