Teaching a new person, I noticed the Windows shortcuts I learned this year

While teaching a new person, I noticed something.
Come to think of it, I learned a lot of Windows shortcuts this year, and my work got much easier.
In network operations work, I write down the date I checked something very often.
So "Ctrl + ;", which puts today's date in Excel, is a must.
In network operations work, I switch between all kinds of apps a lot, like Excel procedure files, management sheets, web apps in Firefox, a knowledge sharing tool, and a chat tool.
If I opened them with the mouse every time, the sun would go down.
In network operations, for example, say there is work to set up a device from 15:00.
But it is still 13:00 now.
At a time like this, keeping the procedure open the whole time feels like a waste somehow, right?
At times like that, I split my desktops.
Like, "I do the 15:00 work on this desktop."
I also recommend it for double-checking before sending an email.
It shows the desktop instantly.
I wish it were this easy to press on a Mac too!
In network operations work, I use a lot of documents.
So I make "islands" of files on my desktop, like the top left, top right, middle, bottom right, and so on.
At times like that, a shortcut that opens the desktop right away is useful.
It opens the "Run" window.
If you paste a folder path here and press Enter, that folder opens at once.
It is much faster than clicking through folders one by one.
This is a little off topic, but the mouse cursor speed should be the fastest.
When I touched a new person's computer, I thought, "This mouse is sooo heavy!"
Set the mouse to the fastest, so that a tiny move takes you from one edge of the screen to the other.
I wonder if there were others. When I remember more, I want to add them 🙂‍↕️
