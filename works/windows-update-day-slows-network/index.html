The network gets tight on Windows Update day every month 🪟

🪟 Update Day

Once a month, on “Windows Update day”, the network gets tight.

📅 Second Wednesday

I think it is the 2nd or 3rd Wednesday, and many companies start updating at once.

📊 A Set Limit

Companies usually have a contract saying how much bandwidth they can use.

📈 To The Limit

On that day they use data right up to the limit, so the network gets tight.
