## 素材（本人の原稿そのまま。これが正）

今回のマレーシア大学見学旅で使ったツールは、この3つです 🐧

GitHub — すべてのデータの置き場です。妹の高校の成績、高校からもらった進学の資料、候補の大学それぞれの情報、最新のチャット履歴など、なんでも入れました。GitHub（クラウド上）で情報を管理しているので、スマホからもパソコンからも、情報を整理したり確認したりできます。
GitHubのいいところは、バージョン履歴が残ることです。履歴が残るおかげで、例えば「間違った情報を登録しちゃった」という時も、いつでも変更前の状態に戻せます。いざとなったら整理前のバージョンに戻ればいいだけなので、安心してAIに情報の整理を丸投げできます。

Claude Code — GitHubの情報を使って、いろいろ相談しました。GitHubの中の情報を整理したり、直したり。妹に関係するメールやWhatsAppが届いていないか、確認させたりもしました。

Claude in Chrome — Chromeでの操作全般を任せました。これがとても便利でした。大学の問い合わせフォームや、ホテル・飛行機の予約など、ブラウザでクリックして入力する作業がたくさん必要なときは、ほとんどこのAIに任せていました。自分で手入力すると、めんどくさいですし、入力を間違えてしまうこともありますからね。

やはり、めっちゃお世話になったのはClaude in Chromeです。

これはClaudeがブラウザの操作を代わりにしてくれるものなんですが、いろんなウェブフォームのぽちぽち作業を代わりにやってもらえたのは、とても助かりました。
