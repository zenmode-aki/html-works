# Perfectionist #3 — Japanese source

S1. 前回の続き。
S2. 完璧主義を捨てるためにやってることの2つ目。
S3. これは自分にとって盲点だったんだけど、
S4. 捨てることを最初に決めておくといい。
S5. 新しく始めたり、付け加えたりするのは、完璧主義者にとってワクワクする作業。
S6. でもそれだと終わらない。
S7. そうじゃなくて、捨てることを3つ決めておく。できれば3つ。
S8. 僕のブログにも完璧主義の血が入ってるので、

S10. だから最初に決めてある。
S11. 1記事は10分以内で書き終える
S12. 1分以内で読める文章量にする
S13. 思ったことをバーっと書く
S14. やらないことを先に決めてるから、
S15. とりあえず外に出せてる。
S16. あとから捨てようとすると、それは「妥協」になってしまう。
S17. でも最初に決めておけば、それは「設計」になる。
S18. 同じことをしてるのに、
S19. 自分の中での扱いが変わる。
S20. 完璧主義って、全部やろうとすることじゃなくて、
S21. 何を諦めたのか自分に説明できないことなのかもしれない。
S22. とにかくやる。
S23. そして、捨てるものを先に3つ決める。
S24. 身も蓋もないけど、今のところこれが一番効いてる。

## Center message

Choose three things to leave out before starting. Giving up later feels like compromise; choosing it first turns it into design.
