If you pass on bad gossip, people start to dislike you too 📮

🧠 Psychology🤝 Friends🫧 Feelings
✉️ The Messenger

Some people tell you, "Someone said bad things about you."

Even if they mean to be kind, it seems people start to dislike the messenger too.

🧠 A Set Memory

This is because the brain remembers the bad feeling and the person in front of it together.
