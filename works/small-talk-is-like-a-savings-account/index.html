Small talk is like a savings account for friendship 🐷

🧠 Psychology🤝 Friends🏫 School
💬 Chat Comes First

It seems we do not chat because we like someone; we like someone because we chat a lot.

🚌 School Trip

For example, on a school trip, you wanted to be in a group with the kids you always talked to, right?

🍩 Silly Talk Only

And only silly little talk is saved as closeness.
