👂 → 🔎 → 🧍 The Wrong Order

Maybe the order is like this.
I listen to many people’s opinions.
Then I start to feel that there is a correct answer in this world.
But I do not know it yet.
So I listen to more.
I have to know more, and more, and in the end I do not move from that place.

🎯 Getting Closer

Each time I learned something, I thought I was getting closer to the correct answer.
But in fact, only one idea was growing: “There is a correct answer.”
